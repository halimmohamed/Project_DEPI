# Project_DEPI
📌 Project Title
PharaohsPath – Smart Tourism Management System for Egypt

📖 Project Overview
PharaohsPath is a web-based tourism management platform designed to enhance the travel experience for tourists visiting Egypt. The system allows users to plan and customize their trips across different Egyptian governorates, book hotels, select tour guides based on ratings, and explore recommended tourist attractions.
The platform also provides an employment opportunity module for tour guides to apply and register in the system.

🎯 Objectives
Simplify trip planning for tourists.
Provide structured tourism programs across multiple governorates.
Enable rating-based selection of hotels and tour guides.
Connect tourists with verified tour guides.
Improve organization and visibility of Egyptian tourism services.

📦 Scope of the Project

✔ Included Features (Prototype Scope)
User Registration & Login (Tourist / Guide / Admin)
Browse governorates and tourist attractions
Create trip plan (Single governorate or multi-governorate)
Select hotel based on rating
Select tour guide based on rating
View trip summary
Guide application form
Basic admin dashboard
